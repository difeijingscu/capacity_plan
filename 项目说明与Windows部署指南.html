算力沙盘（Capacity Sandbox）：项目说明与Windows部署指南

交付版本：应用1.0.0；计算引擎engine-v1.0.0；Windows迁移包，2026-10-21。

1. 项目用途

本项目是面向专业人员的单用户算力规划网页应用，用于根据组织规划期末的AI应用需求，估算业务场景、创新服务、开发测试三个资源池所需的计算能力，并保留计算依据。

规划主体以T/P及必要的计算精度、显存等辅助指标输出，不绑定某一厂商卡型。费用附录可按少量代表性卡型和用户录入的报价进行粗略折算。

本应用不加载或运行被规划的大模型，也不进行实际微调或发放Token，因此运行规划工具本身不需要GPU。模型选择用于确定计算参数与基线。

2. 功能与组织方式

项目、方案和测算记录

- 一个项目管理一次独立的规划工作，可包含多个方案。

- 新建项目自动生成“基准方案”。点击项目卡片中的方案按钮进入具体规划。

- 每个方案独立保存规划周期、规模口径、增长率、余量和三类规划。

- “复制方案”复制输入，方便比较不同假设；复制后的方案各自维护。

- 每个方案可保留多次测算记录，历史结果保存当时输入和模型快照。

- 左侧业务场景、创新服务和开发测试页面跟随当前方案；历史结果选择只改变查看的结果，不改变编辑中的方案。

三类资源池

资源池主要输入处理方法
业务场景Excel或粘贴清单、在线人数、模型、输入输出长度等多组件汇总为场景，多场景汇总为业务池；默认高峰同时发生
创新服务支持人数、人均月Token、模型份额、服务窗口按月额度分配给模型，再转换为服务峰值和容量
开发测试候选模型、实验强度、微调与评测参数按最大单任务能力及并行槽位配置资源

同一方案的三类资源池需求相加，形成方案总需求；同一项目的多个备选方案用于比较，彼此不相加。三池按独立资源配置，同模型不自动跨池共享。

已实现的页面能力

- 业务清单导入、场景与模型配置、参数默认值及点击说明。

- 业务、创新服务、开发测试的独立配置与统一测算。

- 三池规模、显存、缺失任务、依据等级、敏感性与历史版本比较。

- 点击测算结果中的总算力、业务场景、创新服务、开发测试四张卡片，可展开本次输入、公式代入、中间值和汇总过程；历史结果使用当时的测算快照。

- 模型与任务基线管理、来源追踪、参考卡和报价附录。

- “规划依据”详细解释公式、默认假设与参考资料。

- 项目概览提供“规划思路和依据”“规划方案组织设计”两个说明入口。

业务场景页的规划助手已按当前需求移除。日常运行无需连接AI、GitHub或其他云服务；AI接口设置与后端扩展仍保留，不是部署前置条件。

5. 在另一台Windows机器上启动

第一步：复制并完整解压

将Windows运行包ZIP复制到目标机器，右键选择“全部提取”。解压后进入CapacitySandbox目录。请先解压，再启动程序；目录内应同时能看到启动.bat、backend、frontend和runtime。

推荐解压至较短路径，例如D:\Apps\CapacitySandbox。不要只复制启动.bat，也不要直接在压缩包预览窗口内运行。

第二步：检查环境

双击“检查环境.bat”。正常时会显示Python版本、64位架构、依赖检查OK及“环境检查通过”。此步骤不联网下载依赖。

第三步：启动应用

双击“启动.bat”，浏览器将打开：

http://127.0.0.1:8000

首次在该目录启动时会检查数据库并补齐种子模型。迁移包已包含打包时保存的数据，可在项目概览找到已有项目。

第四步：停止应用

关闭浏览器只会关闭页面，后台服务仍可能运行。需要退出或备份时，双击“停止.bat”。下次继续双击启动.bat即可。

6. 端口与数据目录

8000端口被占用

在解压后的项目目录打开PowerShell，执行：

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\启动.ps1 -Port 8008

浏览器将访问http://127.0.0.1:8008。同一目录一次运行一个服务实例；切换端口前先停止该目录已启动的服务。启动器会拒绝将另一个目录下的同类服务当作本目录服务。

单独存放业务数据

默认使用项目目录中的data/planner.db。如果需要单独存放，可在启动前设置：

$env:PLANNER_DATA_DIR = 'D:\PlannerData'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\启动.ps1

新数据目录为空时会初始化为新的工作空间，不会自动读取原data中的项目。要继续已有项目，先停止服务，再将已有数据库备份放入指定目录。以后启动时需继续设置相同环境变量。

服务默认只监听127.0.0.1，供本机浏览器访问。本包未配置局域网多人访问、账号或权限管理。

7. 数据备份、恢复与再次迁移

备份

1. 在网页中保存当前修改，并等待正在运行的计算完成。

2. 双击停止.bat。

3. 复制整个data目录到带日期的备份目录；如果设置了PLANNER_DATA_DIR，备份那个数据目录。

SQLite可能使用planner.db-wal和planner.db-shm辅助文件。手工备份时复制完整数据目录，不在运行中只复制一个.db文件。本次交付包的数据库通过SQLite备份接口生成，已将已提交WAL内容合并为一致性快照。

恢复

1. 先停止目标目录服务，并保留目标现有data作为回退备份。

2. 用完整备份数据替换目标业务数据；恢复到单独目录时，启动前设置PLANNER_DATA_DIR。

3. 不复用其他机器备份中的server.json、server.log和server-error.log；它们是进程与日志文件，不是业务数据。

4. 启动后核对项目、方案及测算记录。

从空白数据开始

停止服务后，将data目录重命名为data-backup，再启动。系统会新建data并初始化模型目录；原项目仍保留在data-backup中。不要在未备份时删除原数据。

API Key不写入数据库，迁移后如确需使用保留的AI后端接口，应重新配置。当前业务规划流程无需该接口。

8. 使用步骤

1. 在项目概览阅读“规划方案组织设计”，理解项目与方案的关系。

2. 选择已有项目的方案，或新建项目；也可载入示例体验。

3. 上传Excel或粘贴业务场景清单，核对任务类型、模型和业务规模。

4. 展开“技术参数与默认值”，查看默认数值；点击感叹号理解参数含义与选择原因。

5. 按需要启用创新服务、开发测试，确认各自参数和统一规划口径。

6. 保存方案并点击“开始测算”，检查缺失任务、三池需求、显存及计算依据。

7. 需要比较其他假设时复制方案；费用附录需先录入有来源的报价。

10. 从源码继续开发

随包源码与已构建网页对应。日常使用无需执行以下步骤。

若需要修改前端或升级依赖，建议使用独立源码工作目录和完整Python安装，不在runtime内直接执行pip升级。随包嵌入式环境用于运行，不含完整的开发工具链。

源码开发已验证的环境为Python 3.13.8 x64、Node.js 24.13.1。Python依赖见backend/requirements.lock.txt；前端依赖由frontend/package-lock.json锁定。

保留源码、移出runtime目录后，在源码根目录执行：

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\安装依赖.ps1 -SkipBrowser

该源码安装步骤需要Python、Node.js/npm和网络，会建立新的.venv、安装锁定依赖、重建网页并执行数据库迁移。Windows运行包日常启动则直接使用runtime和已构建网页。

前端修改后在frontend目录执行npm ci、npm run build；后端与计算测试可在backend目录执行：

..\.venv\Scripts\python.exe -m pytest -q

前端测试在frontend目录执行：

npm test
npm run test:e2e

浏览器端到端测试优先使用Edge，在8010端口和独立测试数据目录运行；没有Edge时，需按开发流程安装Playwright浏览器。

11. 计算口径与当前范围

P/T是本产品定义的参考BF16稠密等效规划口径，效率、请求频次、部分显存预算和实验档位属于透明的早期规划假设。具体公式与来源请阅读应用中的“规划依据”或docs内的详细设计。

缺少可靠基线的任务保留为未计入，不用0冒充完整需求。响应时间、设备互联及实际模型吞吐需要匹配条件下的后续测试。费用附录只作参考折算，不构成整机配置或采购报价。

当前版本为本机单用户应用，不包含部门填报、审核审批、实际资源调度、真实Token发放和模型训练执行。

12. 包完整性与许可证

Windows运行包旁提供ZIP的SHA256校验文件；包内提供文件校验清单.json。可在PowerShell中核对：

Get-FileHash -Algorithm SHA256 -LiteralPath '算力沙盘-Windows-x64-20261021.zip'

Python许可证位于runtime/python/LICENSE.txt；第三方包的许可信息保留在各包或.dist-info目录中。计算设计、代码及业务数据按项目自身的权属管理；本包没有另行授予项目源码的开源许可证。
