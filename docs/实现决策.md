# v1.0 实现决策

- 按已确认范围交付本机单用户应用，未注册或发布外部托管站点。
- 前端使用React、TypeScript、Vite、Ant Design和ECharts，后端使用FastAPI、Pydantic、SQLAlchemy和SQLite。
- 数据采用一张版本化records表存储经过强类型Schema验证的逻辑实体，kind区分项目、方案、不可变计算快照、模型版本、价格版本等。保持设计中的逻辑关系，减少早期单用户版本的迁移复杂度。Alembic维护结构版本。
- 生产构建由FastAPI静态托管；开发模式由Vite代理API。
- 计算引擎只接受规范化输入与模型快照，无AI、网络或数据库依赖，使用Decimal。性能计时不参与计算哈希和容量数值。
- 在线规模预估通过防抖请求调用同一个后端引擎，前端不复制计算公式。
- 特殊架构的官方结构事实与本工具的保守显存代理分开记录；未核验内容保留为null/下界。
- 旧方案、计算、费用都有快照，新基线或新价格不会改写历史数值。
- 所有本地规则助手行为明确标识；第三方AI接口使用结构化提案，白名单验证后才应用。凭据只在内存或环境变量中。
- AI与计算采用持久化任务记录和单进程线程池，应用重启后未完成任务标为INTERRUPTED。
- 网页仅展示结果；未加入Excel/Word/PDF导出。
