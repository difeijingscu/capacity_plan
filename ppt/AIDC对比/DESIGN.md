### P1 封面

- layout：大字报式（纯文字极简，无图）
- visual：无（L3 视觉母题细线即可）
- visual_role：atmosphere
- density：字数约 60 / 图片 0 张 / 留白约 45%
- anti_pattern：禁止出现任何数据指标；禁止加页尾；禁止装饰性 icon 堆砌
- description：主标题「AIDC2026 算力规划方法对比」；副标题「整体层级对位与创新服务池专项口径」；说明层「基于目标站源码逐条还原公式 + 本项目引擎同模型同卡对照验证」；信息层「2026-11-08 · ComputePlanner」

### P2 整体对比：两个不同层级的方法

- layout：对比式（h），左右两区严格对齐，中间 1px 竖线 + 「VS」
- visual：L3 结构化图示（两列各自的 4 个环节，用 SVG 或 Box 色块表达）
- visual_role：evidence
- density：字数约 210 / 图 1 组 / 留白约 18%
- anti_pattern：禁止均分 50:50 双栏（用 6:5 非对称）；禁止把六条差异写成长段落堆叠
- description：左侧 AIDC「业务量 → 单次前向算力 → 卡数 → 显存下限取大 → 机柜/电力/ROI」，标注"一级匡算、无并发无 SLO"；右侧本项目「场景/IO/并发/SLA → 三维约束 → 混部抬升 → SLA 回验 → 三池汇总」，标注"二级容量规划"。底部结论条：「AIDC 强在业务建模与设施经济层，本项目强在单场景容量计算与可审计」

### P3 创新池专项：8 倍差异的精确来源

- layout：巨型数字 + 瀑布分解
- visual：L2 瀑布/阶梯式分解图（SVG 或 Box 色块串联）
- visual_role：anchor
- density：字数约 170 / 图 1 组 / 留白约 15%
- anti_pattern：禁止把 7.99 塞进卡片角落；禁止等宽三栏并列三个倍数
- description：巨型数字 **7.99×**（MoE）/ 7.33×（Dense）；下方三段分解 4.0909（时间基准 22×8h vs 自然日）× 1.20（κ 结构修正）× 1.6286（等效 η 0.2763 vs 0.45）；右侧一条"反向验证：三项逐一拉回 → 残差 1.0000"的证据条；底部注明"与规模/模型/请求长度/峰值倍数均无关"

### P4 结论与补强方向

- layout：左标题色块 + 右内容（m），左栏 32% 放主色块
- visual：L3 三条优先级色带
- visual_role：evidence
- density：字数约 240 / 图 0 张 / 留白约 20%
- anti_pattern：禁止做成均分三卡片；禁止把「谢谢」塞进本页
- description：左栏主色块写「结论 / 三条补强」；右栏三条按优先级：P0 创新池补主链路卡数（`n_card = max(n_compute, n_min)`，数据已备好）、P1 统一两池显存口径、P2 修业务池并发跨 256 后非单调。底部一行提醒：对外不得直接摆「1024 卡 vs 16 卡」
